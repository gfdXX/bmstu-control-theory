## Как запустить

1. Нужен MATLAB с Control System Toolbox и Simulink (проверялось на R2022a). Для фильтра Хампеля — Signal Processing Toolbox.
2. Откройте папку нужной работы в MATLAB (`cd`) и запустите скрипт, например:

   ```matlab
   cd 03-nonlinear-systems/homework
   Task5          % синтез управления со скользящим режимом
   ```

3. Модели `.slx` открываются двойным щелчком или командой `open_system('имя_модели')`.
   Скрипт `03-nonlinear-systems/homework/Task3.m` использует функцию из `03-nonlinear-systems/seminars`, поэтому эту папку нужно добавить в путь: `addpath('../seminars')`.
