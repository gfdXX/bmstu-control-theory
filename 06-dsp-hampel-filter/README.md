# Фильтр Хампеля

Цифровая обработка сигналов.

`lab_hampel.m`:
1. своя функция `hampel_filter` (скользящее окно, медиана и порог в `nsigma` медианных абсолютных отклонений) и сравнение результата со встроенной `hampel`;
2. косинусоида со случайными выбросами: как результат зависит от размера окна `k` (1, 5, 10);
3. тот же сигнал: как результат зависит от порога `nsigma` (1, 5, 10).

Нужен Signal Processing Toolbox (для сравнения со встроенной функцией).
